# Contributing

Cinch is a research-preview statistical workflow. Changes to score definitions,
pair universes, state semantics, thresholds or filters must include:

1. an explicit mathematical specification;
2. a versioned configuration and random seed where relevant;
3. a synthetic positive and negative control;
4. a statement of whether existing results change;
5. tests that separate statistical detection from biological interpretation.

Bug reports should include the command, manifest, software versions and the
smallest redistributable input that reproduces the problem. Do not attach human
identifiers, credentials, controlled-access genomes or unlicensed raw data.
