# Frozen network

The graph is a direct view of `FINAL_CANDIDATES.tsv`: 167 nodes, 223 unique edges,
and eight connected components (151 nodes in the largest). Node size is degree;
color is deterministic greedy-modularity community; edge width is NMI; edge color
is PP/PT/TP/TT. Communities are descriptive, not automatically pathways.

The interactive Cytoscape.js view supports search, zoom/pan/drag, channel toggles,
P↔T-only mode, MIraw/NMI/Neff/order/HC filters, alternate edge coloring and exact
metadata. `gyrB–aguA` and the four PP candidates have spotlight controls. GraphML
and GEXF are included. The graph is pre-ARACNE: ARACNE was not run in this freeze.
